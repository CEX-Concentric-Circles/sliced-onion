# Sliced Onion Project

Welcome to the Sliced Onion project! This repository contains an example of the application of the Sliced Onion architecture in an e-commerce context. The project uses Spring Modulith, Kotlin and Gradle to demonstrate a modular and maintainable architecture.

## Branches

The project is divided into several branches, each representing a development step:

- **Step 1: Implementation** - The first step includes the basic implementation of the architecture and bounded contexts.
- **Step 2: Extension** - In this step, the architecture is extended to integrate additional functionalities.
- **Step 3: Extraction** - The third step shows the extraction of a bounded context into an independent application. This extracted application can be accessed [here](https://github.com/CEX-Concentric-Circles/sliced-onion-inventory).

Each of these steps has its own branch in the repository, which has the same name as the step.

## Technology stack

- **Spring Modulith**: For the modular architecture.
- **Kotlin**: As a programming language.
- **Gradle**: For build management.
- **MySQL**: As a database management system, provided via Docker.
